# Notion Widgets
 
A collection of custom widgets for Notion, built to extend dashboards and workspace templates with interactive elements (trackers, calendars, embeds, and more).
 
## Overview
 
This repo hosts the source code for widgets used across Notion templates, including habit trackers, day/month displays, and other embeddable components. Each widget is self-contained and can be embedded in Notion via an iframe or embed block.
